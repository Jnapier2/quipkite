# Security Policy

## Supported public surface

Security reports should concern the current simulated Solo preview or this showcase repository. Unpublished builds and future online-service concepts are outside the supported public surface.

## Reporting

Use GitHub's private vulnerability-reporting option when it is available. If private reporting is unavailable, contact the repository owner through the linked GitHub profile before sharing sensitive details. Do not place credentials, personal information, exploit payloads, or private user data in a public issue.

The public preview has no real-person matchmaking, production accounts, payments, or automatic product telemetry. Please do not test third-party hosting infrastructure or other users' systems.
